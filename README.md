# Hydrabean — Luxury & Adventure Travel Agency

A luxury travel agency web application built with [Next.js](https://nextjs.org/) (App Router), [Tailwind CSS](https://tailwindcss.com/), [Framer Motion](https://www.framer.com/motion/), and [Three.js](https://threejs.org/).

## ✨ Features

- **Immersive Experiences:** 3D interactive hero, smooth inertial scrolling via Lenis, and kinetic GSAP animations.
- **Tailored Pages:**
  - **Home:** Interactive 3D hero journey, destinations showcase, reviews constellation, and travel network.
  - **About Us (`/about`):** The story of Hydrabean, our 4 core pillars, expedition directors, and milestones timeline.
  - **Services (`/services`):** 6 core expedition pillars with category filters, our 4-step concierge protocol, and guaranteed traveler protections.
  - **Prices (`/prices`):** Transparent per-trip and annual pass pricing tiers (*Explorer*, *Signature*, *Elite*, *Group/Corporate*), side-by-side feature matrix, add-on experiences, and interactive FAQ.
  - **Contact Us (`/contact`):** Direct phone/email concierge lines, international studios (Tokyo, London, NYC, Zürich), and a multi-step bespoke travel inquiry form with instant confirmation.
- **Responsive & Accessible:** Glassmorphic design system tailored for desktop, tablet, and mobile devices.

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS, Syne & Space Grotesk Google Fonts
- **Animation:** Framer Motion, GSAP, Lenis Smooth Scroll
- **3D Graphics:** Three.js, React Three Fiber & Drei
